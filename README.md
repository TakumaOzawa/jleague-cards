# jleague-cards

「Jリーグとほほ探索記・番外編5（ドリップ）」で使うクラブカード画像の置き場です。

note のインポート機能は、`img` タグの `src` が http(s) の画像URLのときだけ画像を取り込み、
**画像自体を note 側に保存し直します**。そのため、このリポジトリは note へのインポート中だけ
公開されていれば足ります。インポートの完了を確認したあと、削除する予定の一時的なものです。

- 画像は 61 枚（2026年のJリーグ60クラブ＋JFLへ去るアスルクラロ沼津）
- 各カードの Elo・過去最高・3つの期待とのズレは、筆者が作った簡易モデルによるものです
- 本文・データ・生成スクリプトはこのリポジトリには含みません
